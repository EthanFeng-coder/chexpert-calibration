# Data Accessibility

## Public repository statement

The code scaffold, environment files, configuration structure, reproducibility notes, and data-access documentation for this paper are available in this repository.

The raw CheXpert chest radiograph images are third-party medical imaging data and are not redistributed by the authors due to the dataset's access and licensing terms. CheXpert can be requested from the official Stanford ML Group repository:

<https://stanfordmlgroup.github.io/competitions/chexpert/>

For reproducibility, permitted derived outputs, aggregate performance results, calibration outputs, bootstrap confidence interval outputs, random seeds, and scripts may be added to this repository or to an archival record when release is appropriate.

Any external-domain datasets used in the study should be obtained from their original providers subject to their respective access terms. Raw third-party medical images, identifiable patient data, credentials, API keys, tokens, and private local paths should not be committed to this repository.

## Intended contents

- Code for post-hoc calibration and evaluation.
- Environment files: `environment.yml` and `requirements.txt`.
- Configuration files documenting seeds, paths, models, and evaluation settings.
- Derived calibration outputs where permitted.
- Aggregate results where permitted.
- Bootstrap confidence interval outputs where permitted.
- Documentation explaining how to obtain the restricted raw datasets.
